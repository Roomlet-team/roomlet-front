<h1 align="center">👏 Roomlet</h1>
<div align="center" >
  Roomlet은 모바일 웹 기반 회의실 예약 및 일정 관리 솔루션 입니다.<br />
</div>

## 기능  
📖 중복 예약 걱정 없이 편리하게 회의 일정을 관리할 수 있어요   
📆 메인 화면에서 오늘 회의 일정을 한 눈에 바로 확인할 수 있어요   
🔎 회의 필터 기능을 통해 쉽게 회의를 찾을 수 있어요   
👥 여러 명에게 관리자 권한을 부여하고 함께 워크스페이스를 관리할 수 있어요

## 폴더 구조
📦public : 정적 파일   
 ┣ 📂styles : 스타일 파일  
📦src  
 ┣ 📂assets : 로고 등의 이미지 리소스  
 ┣ 📂components : 특정 기능이나 서비스에 국한되지 않고, 공통으로 사용되는 아이콘 및 UI 컴포넌트  
 ┃ ┣ 📂icons : 아이콘  
 ┃ ┃ ┗ 📂types : 아이콘 컴포넌트에서 사용되는 타입  
 ┃ ┗ 📂ui : 공통 UI  
 ┣ 📂config : 환경 변수    
 ┣ 📂features : 기능별 함수 및 컴포넌트를 정리한 폴더
 ┣ 📂hooks : hook 모음  
 ┣ 📂layouts : 룸렛에서 공통적으로 사용되는 레이아웃 모음  
 ┣ 📂pages : 페이지 라우팅 폴더  
 ┣ 📂store :   
 ┣ 📂utils : 자주 사용되는 함수 모음  
 ┗ ┗ 📂api
